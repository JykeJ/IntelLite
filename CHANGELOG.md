# Changelog

## 0.1.0

First public release.

* Five native SkyrimNet actions: Fetch Person, Deliver Message, Meet Later, Assassinate
and Cancel All.
* MagelightUI panel and consent card.
* Package travel with off-screen deadlines, door and gate staging, and a simulation
fallback.
* World-wide NPC index, fuzzy name resolution and an editorid blacklist.
* SkyrimNet awareness submodule.
* One DLL for SE and AE, tested on 1.6.1170. SE 1.5.97 and other AE / 1.7.x builds are
untested
